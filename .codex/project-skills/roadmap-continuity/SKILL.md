# Roadmap Continuity

## Workflow

1. Load `docs/roadmap/SEQUENCING.md`.
2. Check `docs/NEXT_STEPS.md`, `docs/ACTIVE_TASKS.md`, and `docs/CURRENT_STATE.md`.
3. Separate current implementation from stabilization, deferred architecture, orchestration readiness, topology intelligence, and utility integration.
4. Avoid turning future-phase intent into current capability.
5. Update root discovery files when roadmap direction materially changes.

## Checks

- no deferred capability is described as live
- sequencing preserves implementation velocity
- trust/provenance work precedes stronger claims
- migration and continuity risks remain visible
