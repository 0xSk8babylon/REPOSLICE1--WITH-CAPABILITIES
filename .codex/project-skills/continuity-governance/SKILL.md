# Continuity Governance

## Workflow

1. Start with root discovery: `AGENTS.md`, `PROJECT_STATE.md`, `discovery-index.md`.
2. Use `docs/continuity/LEAN_RESTORE_WORKFLOW.md` for restore changes.
3. Use `docs/continuity/UNRESOLVED_ARCHITECTURE.md` for open architecture continuity.
4. Update compact discovery files first; update detailed docs only when affected.
5. Create a dated handoff after meaningful architecture or implementation work.

## Rules

- keep restore prompts short
- avoid full-doc sweeps by default
- do not duplicate the same state summary across every file
- surface code/doc mismatches explicitly
