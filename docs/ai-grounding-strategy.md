# AI Grounding Strategy

## Grounding Policy

AI is an explanation and interaction layer, not the source of equipment facts, engineering assumptions, or code interpretations.

## Authoritative Inputs

- Home and building records
- Electrical distribution context
- Structured load records
- Product library entries with verified manufacturer data
- Compatibility and calculation outputs
- User goals and scenario framing

## Expected AI Behavior

- cite the structured context it is using
- explain tradeoffs in plain language
- distinguish between known facts, assumptions, and open questions
- refuse to invent unsupported product capabilities
