# Roadmap Sequencing

## Current Implementation

- SQLite-backed planning persistence
- editable core planning workflows
- deterministic advisor and scenario comparison layers
- visible trust and provenance surfaces
- scenario revision foundation
- current-home topology and structured reasoning graph

## Stabilization Phases

1. Expand provenance coverage across design, scenario, topology, and home-model facts.
2. Normalize migration practice around Alembic before substantial schema growth.
3. Strengthen solar readiness and roof-capacity realism without claiming production modeling.
4. Preserve transient takeoff boundaries until versioned snapshot rules are designed.

## Deferred Architecture

- full audit trail
- delete/archive workflows
- versioned takeoff snapshots
- field verification workflow
- deployment lineage manifest
- production tenancy and RBAC

## Orchestration Readiness

1. Define orchestration-safe context envelopes.
2. Define topology lifecycle authority stages.
3. Define contractor-safe and utility-safe output scopes.
4. Add deployment and migration lineage docs.
5. Only then consider runtime orchestration behavior.

## Topology Intelligence Phases

1. Planning topology: current state, proposed state, scenario revision.
2. Verification topology: field-observed equipment and site constraints.
3. Operational topology: commissioned devices and control boundaries.
4. Lifecycle topology: replacements, decommissioning, expansion, and DER participation.

## Utility Integration Phases

1. Utility-safe abstraction definitions.
2. Source-linked tariff/program references.
3. Interconnection state tracking.
4. Submission support only after authority and audit boundaries exist.
