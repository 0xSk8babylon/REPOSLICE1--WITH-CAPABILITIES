# ADR 0005: Living House Model As Core Domain

## Status

Accepted

## Context

Residential energy planning is often reduced to proposal generation, but this repository is organized around persisted home context, evolving designs, loads, products, and pathways.

## Decision

The core domain is the living house model over time, not a one-time quote artifact. The platform should preserve persistent property and infrastructure context as the foundation for future planning and explanation.

## Consequences

- Domain modeling should favor long-lived house context.
- One-off proposal patterns should not dominate architecture decisions.
- Future features should reinforce continuity, comparison, and expansion reasoning.
