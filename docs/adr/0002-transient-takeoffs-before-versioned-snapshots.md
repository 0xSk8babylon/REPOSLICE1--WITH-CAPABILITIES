# ADR 0002: Transient Takeoffs Before Versioned Snapshots

## Status

Accepted

## Context

Takeoffs are currently derived from live design composition, while provenance depth, estimate confidence, and snapshot rules remain incomplete.

## Decision

Takeoffs remain transient planning views until intentional versioned snapshot semantics, lineage expectations, and downstream trust rules are designed.

## Consequences

- Current takeoffs must remain visibly provisional.
- Future snapshot persistence should be introduced deliberately, not as an incidental convenience feature.
- Stronger estimating claims should wait for stronger provenance and snapshot governance.
