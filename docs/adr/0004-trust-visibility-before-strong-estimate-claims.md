# ADR 0004: Trust Visibility Before Strong Estimate Claims

## Status

Accepted

## Context

The product includes placeholder values, demo data, derived estimates, and partial provenance. Users still need planning help before the system can support stronger factual claims.

## Decision

The system should prioritize visible trust posture and uncertainty signaling before adding stronger estimate, pricing, or verification claims.

## Consequences

- Derived outputs should surface basis and limitations.
- Provenance depth should increase before the product speaks with more authority.
- Future work that sharpens claims without improving lineage should be challenged.
