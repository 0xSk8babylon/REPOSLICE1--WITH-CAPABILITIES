Residential Energy Planner

Interactive product and technical architecture map.

A self-contained planning map generated from the repository architecture cockpit, UI Registry, and project docs. It does not call APIs, write data, or change application code.

Boundary

Internal visibility only. Product placement is planning metadata, not approval, compliance, pricing, permission, or final design authority.

Inventory

Capability counts and V1 visibility from the frontend UI Registry.

Map Controls

Switch between product, UI, technical, and full architecture views.

Product Grouping

The intended planning groups for future Home, Planner, Build, and Hidden/Internal surfaces.

Alignment and Export

Static validation between UI Registry source capabilities and architecture cockpit product capability IDs.
